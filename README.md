# 最小生成樹互動教室

以 Kruskal、Prim、Union-Find 與 Min-Heap 為核心的資料結構教學網站。網站不是只顯示最後答案，而是先完整執行演算法、保存每一步快照，再讓使用者逐步播放、倒退或進入闖關模式作答。

- 線上網站：部署完成後補上
- GitHub：部署完成後補上

## 功能

- 00–04 完整教學章節：定義、玩法、互動遊戲、演算法原理、程式架構。
- 演示模式：上一步、下一步、自動播放、重來與鍵盤控制。
- 闖關模式：預測下一條邊、收下或跳過、目前總重等題目，並統計分數、連對與正確率。
- 六個關卡：
  1. Kruskal 校園地圖。
  2. Prim 從 A 出發。
  3. Prim 改從 F 出發。
  4. 權重平手、MST 不唯一。
  5. 多次成環與路徑壓縮。
  6. 不連通圖與最小生成森林。
- 圖形同步：檢查中、已收下、成環／舊票淘汰與頂點狀態。
- 資料結構同步：排序邊、`parent[]`、優先佇列、`inTree[]`。
- 程式同步：C++17 程式逐行高亮與白話說明。
- 統計與歷程：收邊數、總重、處理數、淘汰數與最近步驟。
- 手機、平板與桌面響應式版面。
- JavaScript 初始化錯誤提示與靜態初始內容，避免只剩空白介面。

## 執行流程

### 1. 選擇關卡

每個關卡包含：

```js
{
  tag: "Kruskal",
  name: "校園地圖",
  algo: "kruskal",
  nodes: [...],
  edges: [...],
  intro: "...",
  finish: "..."
}
```

頂點保存名稱與 SVG 座標；邊保存兩端與權重。

### 2. 建立步驟快照

`mst-engine.js` 的 `build()` 會依 `algo` 執行 Kruskal 或 Prim。演算法每個重要動作都會建立 step：

```js
{
  kind: "take",
  current: "e2",
  selected: ["e2"],
  rejected: [],
  total: 1,
  parent: [0, 1, 1, 3, 4, 5],
  line: 13,
  title: "收下 B–C，總重 1"
}
```

畫面只讀取 `steps[目前索引]`。按上一步時只需把索引減一，不必反向拆除併查集或還原優先佇列。

### 3. 畫面同步

`app.js` 的 `render()` 同時更新：

1. SVG 邊與頂點。
2. 排序邊或優先佇列。
3. `parent[]` 或 `inTree[]`。
4. 收邊數、總重、處理數與淘汰數。
5. 步驟標題、白話解說與歷程。
6. C++ 程式高亮與該行說明。

### 4. 闖關模式

關鍵 step 可附帶 `quiz`。使用者進入該步驟前先作答；系統記錄：

- 分數：答對基本 10 分，連對另有加分。
- 連對：答錯歸零。
- 正確率：答對題數 ÷ 已答題數。

作答後才前進到對應快照，使用者能立即對照答案與圖形變化。

## Kruskal

1. 將所有邊依 `(權重, u, v)` 排序。
2. 初始化 `parent[x] = x`。
3. 對每條邊計算兩端的 `find()`。
4. 代表相同：兩端已連通，加入會成環，跳過。
5. 代表不同：`union` 合併兩組、收邊並累加權重。
6. 連通圖收滿 `V−1` 條邊後停止。

時間複雜度由排序主導，為 `O(E log E)`。`find()` 使用路徑壓縮，後續查找接近常數時間。

## Prim

1. 將起點票 `(0, start, none)` 放入 Min-Heap。
2. 每次取出權重最小的 `(w, v, from)`。
3. 若 `v` 已在樹內，該票已失效，直接丟棄。
4. 否則用 `from–v` 收邊並讓 `v` 進入樹。
5. 將 `v` 通往樹外頂點的邊放入 Min-Heap。
6. 佇列清空後完成。

時間複雜度為 `O(E log V)`，空間複雜度為 `O(V + E)`。

## 特殊情況

### 權重平手

同權重邊依端點字母排序，使動畫與結果固定。平手圖可能有不同的 MST，但最小總重相同。

### 不連通圖

不連通圖無法產生一棵涵蓋全部頂點的生成樹。Kruskal 會讓每個連通元件各自形成 MST，合稱最小生成森林；若有 `C` 個元件，答案共有 `V−C` 條邊。

## 本機執行

專案不需安裝前端套件。

```bash
python -m http.server 5173
```

開啟 `http://localhost:5173`。也可以在 VS Code 使用 Live Server 開啟 `index.html`。

## 測試

需要 Node.js 18 以上版本：

```bash
npm test
```

測試內容：

- 六個關卡都能產生完整步驟與完成狀態。
- Kruskal 與 Prim 校園圖總重均為 13。
- Prim 從 A 或 F 出發都得到總重 13。
- 平手關仍得到總重 13。
- 成環關包含至少兩次淘汰與路徑壓縮。
- 不連通圖得到兩棵樹、4 條邊、總重 8。
- 每個關卡至少產生一道闖關題。

## 載入可靠性

上一版使用 ES Modules；若瀏覽器、快取或伺服器沒有正確載入其中一個模組，整個互動畫面可能保持空白。本版改為：

1. 傳統 `<script defer>`，先載入引擎、再載入畫面控制器。
2. HTML 內保留初始邊清單、C++ 行與載入提示。
3. `boot()` 完成後才隱藏載入提示。
4. 全域錯誤監聽會顯示實際錯誤，不再無聲失敗。
5. 演算法引擎使用 UMD，可同時供瀏覽器與 Node.js 測試載入。
